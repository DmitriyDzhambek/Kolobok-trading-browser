# Kolobok Trading Browser

This project repository now includes the full Kolobok Trading Browser application package, which was added to the project as a complete working source archive.

## What was added to the project

- Frontend application based on Vite and React
- Trading view / charting UI components
- Browser-based trading interface
- Speech service integration
- Telegram-related service integration
- API layer for news and backend communication
- Python backend for processing and service logic
- Docker configuration and service setup for backend deployment
- Electron wrapper for desktop application support

## Included archive

The repository contains the project archive:

- `kolobok-trading-browser-backend-v4.zip`

This archive includes the full project structure under:

## Project structure overview

- `src/` — frontend logic and UI
- `api/` — API endpoints and integration code
- `backend/` — Python backend and environment configuration
- `electron/` — desktop application entry point
- `README.md` — project overview
